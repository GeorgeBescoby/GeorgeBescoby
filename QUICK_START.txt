1. INSTALL NODE.JS (One-Time Only)
   → Go to: https://nodejs.org
   → Download and install (click Next, Next, Finish)

2. RUN THE APPLICATION
   → Double-click "START.bat" in this folder
   → Wait 1-2 minutes (first time only)
   → Your browser will open automatically!

3. GET YOUR API KEY
   → Go to: https://platform.openai.com/api-keys
   → Create a new key
   → Copy it (looks like: sk-abc123...)

4. USE THE APP
   → Click "Set API Key" and paste your key
   → Upload the "sample_leads.csv" file
   → Try the "SOC2 Compliance" quick template
   → Click "Enrich All Rows"
   → Export your results!
